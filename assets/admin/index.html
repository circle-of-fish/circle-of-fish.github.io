Circle of the Fish 편집
저장하지 않은 변경

편집하려면 GitHub 토큰이 필요합니다

이 사이트에는 서버가 없습니다. 편집 내용은 브라우저에서 곧바로 저장소에 커밋되고, GitHub Actions가 사이트를 다시 만듭니다. 그래서 저장소에 쓸 수 있는 토큰이 하나 있어야 합니다.

토큰 만드는 법 (처음 한 번만, 2분)
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token 을 엽니다.
  2. Resource owner를 circle-of-fish 조직으로 바꿉니다.
  3. Repository access에서 Only select repositories → circle-of-fish.github.io.
  4. Permissions → Repository permissions → Contents를 Read and write로 둡니다. 다른 권한은 건드리지 않습니다.
  5. 만료일을 정하고 Generate token. 화면에 한 번만 보이는 github_pat_… 문자열을 복사해 아래에 붙여넣습니다.

토큰은 이 브라우저에만 저장되며 어디로도 전송되지 않습니다 — github.com 말고는. 공용 컴퓨터라면 아래 “이 브라우저에 기억” 체크를 풀어 두십시오. 창을 닫으면 지워집니다.
