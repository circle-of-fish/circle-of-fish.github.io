考底利耶始终不曾问过鱼：做一条鱼究竟是什么滋味。

我们是韩国的青年国际关系学者。我们试图重新发掘东亚——以及东亚之外诸多世界——理解「国际」的存在论，以此推动国际关系学的全球化。

重审「鱼之法则」

关于「河豚会」这个名字

然而刑罚之法一旦废弛，便生出如「鱼之谚」（matsyanyayamudbhavayati）所言的乱象：无执刑罚者（dandadharabhave）之时，强者吞噬弱者；唯有在其护佑之下，弱者方能抗衡强者。 考底利耶《政事论》第一卷第四章——据 R. Shamasastry 英译（1915）转译

「河豚会」这个名字，是我们对考底利耶「鱼之法则（matsya nyāya）」的一个善意反驳。作为南亚版本的无政府状态下的丛林法则，考底利耶在《政事论》中写道：没有国家的生活，就像生活在充满掠食冲动的池塘里的鱼。大鱼吞小鱼之时，鱼之法则便得以贯彻。在霍布斯式的无政府状态中，国家同样活在鱼之法则之下。

然而遗憾的是，正如霍布斯不曾问过狼，考底利耶也没有费心去问鱼本身：做一条鱼究竟是什么滋味。一群河豚大概不会在考底利耶的鱼之法则中认出自己。它们过着相当具有建设性、甚至称得上艺术的生活——在海底筑起纹样繁复的圆环，正如本页所见。

我们就是这样一群像河豚的韩国青年国际关系学者。我们当中许多人，在当下国际关系学科的理论与叙事里认不出自己。虽然各自研究的题目大相径庭，这一存在论上的关切却把我们联结在一起。

与此同时，我们也并不是河豚。做一只河豚究竟是什么滋味，我们并不知道。因此我们想要学习它们的方式，以及河豚之外众多存在者的方式：中国人、日本人、欧洲人、美国人、原住民、非人类、赛博格、海洋、贝壳、外星人……。这种学习本身就是我们的政治。在国际政治之外，还有世界间（inter-world）的政治。

不过，我们从东亚开始，因为它离我们最近。简言之，我们希望通过探究东亚及其之外的存在论，推动国际关系学的全球化。

我们的取向

理论与方法论上的承诺

把河豚会联结起来的，不是共同的研究对象，而是共同的怀疑：学科视为理所当然的那些存在者——在无政府状态下依循单一生存逻辑追求安全的主权国家——不过是切分「国际」的一种历史上特定的方式，却被误认为唯一的方式。以下的一切，都源于认真对待这一怀疑。

理论取向
  1. 秩序不止于文化多样，而具有存在论复杂性
  2. 政体间秩序，而非国际体系
  3. 秩序由社会文化力量造就，而非仅由国家造就
  4. 等级被种族化、被性别化，并被穿戴于身体之上
  5. 以复合化实现多元化，而非以国别学派
方法论取向
  1. 以意逆志：以己意逆求作者之志
  2. 跨越不可通约记录群的多语种档案工作
  3. 概念史与「过去的未来」
  4. 历史过程追踪与比较个案研究
  5. 诠释性社会科学与「由内而知」
研究计划

我们要做的事

四个目标

  • 01发掘东亚国际关系中被边缘化的存在论
  • 02把东亚本土关于「国际」的话语与当代国际关系理论接通
  • 03将长时段的东亚国际关系史纳入现代国际秩序的历史叙述
  • 04通过研究东亚国际关系，推动国际关系学的多元化
